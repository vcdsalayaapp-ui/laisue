# เว็บไซต์ลายสือ (LAISUE)

เว็บไซต์แบบไฟล์นิ่ง (static site) สองภาษา ไทยและอังกฤษ สลับภาษาได้ที่ปุ่ม ไทย | EN มุมขวาบน ผู้เข้าชมครั้งแรกจะเห็นภาษาตามภาษาของเบราว์เซอร์ และเว็บจำภาษาที่เลือกไว้ วางบน GitHub Pages ได้ ประกอบด้วย

- `index.html` หน้าเว็บทั้งหมด
- `assets/` ไอคอนโปรแกรมและภาพหน้าจอลายสือ 2.8
- `.nojekyll` ไฟล์ว่าง บอก GitHub Pages ให้แสดงไฟล์ตามที่อัปโหลด

## วางเว็บบน GitHub Pages

1. ลงชื่อเข้าใช้ GitHub ด้วยบัญชีที่ใช้ทำเว็บ
2. สร้างคลังใหม่ (New repository) ตั้งชื่อ เช่น `laisue` เลือก Public
3. ในคลังนั้น กด Add file › Upload files แล้วลาก `index.html` โฟลเดอร์ `assets` และ `.nojekyll` ไปวาง กด Commit changes
4. ไปที่ Settings › Pages ในช่อง Source เลือก Deploy from a branch เลือก branch `main` และโฟลเดอร์ `/ (root)` กด Save
5. รอสักครู่ เว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/laisue/`

## วางแฟ้มดาวน์โหลด

แฟ้ม .dmg มีขนาดเกิน 100 MB ซึ่งเป็นขนาดสูงสุดของแฟ้มในคลัง จึงต้องวางใน Releases

1. ในคลัง กด Releases › Create a new release ตั้ง tag เป็น `v2.8`
2. แนบ `LAISUE-2.8-AppleSilicon.dmg`, `LAISUE-2.8-Intel.dmg`, คู่มือ PDF และแบบฟอร์ม A4 PDF แล้วกด Publish release
3. คลิกขวาที่ชื่อแต่ละแฟ้มในหน้า Release เลือกคัดลอกลิงก์ แล้วนำไปใส่ใน `index.html`

## แก้ข้อมูลบนเว็บ

ข้อมูลที่เปลี่ยนได้ทั้งหมดอยู่ในส่วน `const SITE = { … }` ช่วงท้ายของ `index.html` (แก้ได้ในหน้าเว็บ GitHub ด้วยปุ่มรูปดินสอ) ค่าชุดเดียวใช้กับทั้งสองภาษา ส่วนเนื้อหาภาษาไทยอยู่ใน `<main data-l="th">` และภาษาอังกฤษอยู่ใน `<main data-l="en">`

- `github.owner` และ `github.repo` ชื่อบัญชีและชื่อคลัง เมื่อกรอกแล้ว เว็บจะนับยอดดาวน์โหลดแฟ้ม .dmg จาก Releases ให้อัตโนมัติ
- `downloads` ลิงก์ดาวน์โหลดสี่แฟ้ม ช่องที่ว่างจะแสดงปุ่ม "ยังไม่เปิดให้ดาวน์โหลด"
- `ethics` หน้ารับสมัครจะเปิดก็ต่อเมื่อกรอก `approvalNo` (เลขที่รับรองจากคณะกรรมการจริยธรรม) แล้วเท่านั้น ใส่ลิงก์แฟ้มประกาศฉบับที่คณะกรรมการรับรองใน `announcementUrl` และลิงก์ Google Form ของบัญชีมหาวิทยาลัยใน `studentFormUrl` และ `expertFormUrl`
- `institutions` รายชื่อสถาบันที่นำไปใช้ ใส่ชื่อภาษาอังกฤษใน `nameEn` ด้วยได้
- `ethics.announcementUrlEn` ประกาศรับสมัครฉบับภาษาอังกฤษ ใส่เฉพาะเมื่อคณะกรรมการรับรองฉบับนั้นไว้ ถ้าว่าง หน้าภาษาอังกฤษจะลิงก์ไปฉบับภาษาไทย
- `fonts` ฟอนต์จากผู้ใช้ ใส่เฉพาะรายที่ได้รับความยินยอมแล้ว และต้องตั้ง `consent: true` รายการที่ไม่มีค่านี้จะไม่แสดง ภาพตัวอย่างฟอนต์ให้อัปโหลดไว้ในโฟลเดอร์ `fonts/` ของคลัง

เว็บไซต์ไม่มีระบบเก็บข้อมูลผู้เข้าชม และไม่มีแบบฟอร์มรับข้อมูลในตัวเว็บ
